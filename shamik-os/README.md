# SHAMIK.OS

A responsive, animated personal developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and a light glassmorphism visual system.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Profile photo

Add your photo at:

```text
public/profile.jpg
```

The profile node has a built-in placeholder if the file is missing.

## Design system

- Warm ivory / sage / olive light theme
- Frosted glass surfaces
- Deep forest typography for contrast
- Acid-green system accent
- Technical grid and subtle grain
- Scroll-linked parallax and reveal motion
- Responsive mobile navigation
- Reduced-motion support

## Included projects

Only three projects are shown:

- Rigor
- SmartHR
- DemenCure

Project content lives in `src/data/projects.js` so additional completed work can be added later without rewriting the UI.
